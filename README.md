# 🎯 شریف رگ‌اسنایپر (Sharif RegSniper)

**Sharif RegSniper** یک افزونه مدرن و فوق‌سریع تحت استاندارد **Manifest V3** برای مرورگرهای خانواده کرومیوم (Google Chrome, Microsoft Edge, Brave و ...) است که جهت تسهیل و خودکارسازی فرآیند انتخاب واحد در سامانه آموزش دانشگاه صنعتی شریف (`my.edu.sharif.edu`) طراحی شده است.

---

## ✨ امکانات و ویژگی‌های کلیدی

- ⚡ **شکارچی بلادرنگ ظرفیت (Live WebSocket/Redux Hunter):**
  - اتصال مستقیم به جریان داده‌های زنده و وب‌سوکت سامانه شریف.
  - شکار و شلیک فوری (زیر ۵۰ میلی‌ثانیه) در صورت باز شدن ظرفیت توسط دانشکده یا انصراف دانشجو، بدون نیاز به رفرش مداوم صفحه.
- 📋 **صف اولویت‌بندی پیشرفته (Priority Queue):**
  - امکان تعیین اولویت دقیق دروس با دکمه‌های انتقال به بالا (▲) و پایین (▼).
  - پشتیبانی کامل از **ترکیب عملیات اخذ و حذف**: امکان قرار دادن همزمان درخواست‌های ثبت‌نام (`➕ اخذ`) و انصراف (`🗑️ حذف`) در یک صف با اجرای ترتیبی و گام‌به‌گام.
- 🗑️ **بخش اختصاصی دروس اخذ شده و حذف سریع:**
  - شناسایی خودکار دروس ثبت‌شده دانشجو به همراه تعداد واحدها.
  - دکمه‌های «حذف سریع» (Fast Drop) تک‌کلیک و «افزودن به صف حذف».
- ⏱️ **زمان‌بندی میلی‌ثانیه‌ای و آفست شبکه (Millisecond Precision):**
  - تنظیم ساعت، دقیقه، ثانیه و آفست بر حسب میلی‌ثانیه برای شلیک در اولین لحظه باز شدن پرتال.
  - دکمه اختصاصی **«⚡ محاسبه آفست»** جهت اندازه‌گیری دقیق پینگ و اختلاف ساعت محلی با سرور شریف.
  - تبدیل هوشمند ساعت ۱۲ ساعته به ۲۴ ساعته.
- 🛡️ **مدیریت هوشمند نرخ درخواست و خطای ۴۲۹ (Rate-Limit Protection):**
  - رعایت خودکار قوانین سرور شریف (حداقل فاصله ۱۵ ثانیه‌ای برای هر درس).
  - مکث و بازگشت تدریجی (Exponential Backoff) در صورت اعمال محدودیت توسط فایروال Nginx جهت جلوگیری از بلاک شدن نشست کاربری.
- 🔊 **سینتی‌سایزر صوتی اختصاصی (Web Audio API):**
  - پخش هشدارهای صوتی متفاوت و ملودیک برای ثبت موفق، هشدارها و خطاهای نشست کاربری بدون نیاز به فایل‌های صوتی حجیم خارجی.
- 💾 **ذخیره‌سازی پایدار تنظیمات (Auto-Save Persistence):**
  - ذخیره خودکار صف دروس، زمان‌بندی، آفست و وضعیت صدا در `localStorage`.
  - امکان درون‌ریزی (Import) و برون‌ریزی (Export) سریع تنظیمات جهت اشتراک‌گذاری با سایر دانشجویان.
- 🔒 **امنیت و مبهم‌سازی پیشرفته (High-Grade Obfuscation):**
  - مجهز به خط لوله اختصاصی بیلد و فشرده‌سازی با `javascript-obfuscator` جهت رمزنگاری رشته‌ها، شکستن جریان کنترل و ممانعت از دستکاری کدهای اجرایی.

## 🚀 راهنمای نصب و راه‌اندازی

### روش اول: استفاده مستقیم از پوشه آماده (`dist`)

1. این مخزن را دانلود یا کلون کنید:
   ```bash
   git clone https://github.com/cheetahcoder/RegSniper.git
   ```
2. مرورگر خود (Chrome / Edge / Brave) را باز کرده و به آدرس مدیریت افزونه‌ها بروید:
   - در گوگل کروم: `chrome://extensions`
   - در مایکروسافت اج: `edge://extensions`
3. در گوشه بالای صفحه، گزینه **Developer mode** (حالت توسعه‌دهنده) را فعال کنید.
4. روی دکمه **Load unpacked** (بارگذاری بسته باز شده) کلیک کرده و پوشه `dist` موجود در پروژه را انتخاب کنید.
5. وارد سامانه انتخاب واحد شریف (`https://my.edu.sharif.edu/`) شوید؛ پنل اسنایپر به صورت خودکار به صفحه تزریق می‌شود!

---

### روش دوم: بیلد از روی سورس‌کد (برای توسعه‌دهندگان)

در صورتی که کدهای سورس در `src/` را ویرایش کردید، با استفاده از مراحل زیر پکیج توزیع را مجدداً بسازید:

1. نیازمندی‌های بیلد را نصب کنید:
   ```bash
   npm install
   ```
2. اسکریپت بیلد و مبهم‌سازی را اجرا کنید:
   ```bash
   npm run build
   ```
3. اجرای آزمون‌های اعتبارسنجی پکیج Manifest V3:
   ```bash
   npm test
   ```
   فایل‌های نهایی در پوشه `dist/` تولید و آماده بارگذاری در مرورگر خواهند بود.

## ⚙️ نکات مهم و توصیه‌های استفاده

1. **فاصله بین درخواست‌ها (Delay):**
   - پیشنهاد می‌شود مقدار تاخیر بین درخواست‌ها را روی بازه **۱۳۰۰ تا ۱۵۰۰ میلی‌ثانیه** تنظیم نمایید. قرار دادن مقادیر زیر ۱۰۰۰ میلی‌ثانیه ممکن است منجر به دریافت خطای ۴۲۹ (Too Many Requests) از سوی Nginx دانشگاه شود.
2. **محاسبه آفست:**
   - چند دقیقه قبل از شروع انتخاب واحد، روی دکمه **«⚡ محاسبه آفست»** کلیک کنید تا تاخیر مسیر اینترنت شما تا سرورهای دانشگاه و اختلاف ساعت سیستم به صورت خودکار اندازه گرفته و در فیلد مربوطه قرار گیرد.
3. **حالت آماده‌باش (Standby):**
   - پس از زدن دکمه «شروع اسنایپر»، در صورتی که زمان در آینده تنظیم شده باشد، ربات در حالت آماده‌باش قرار می‌گیرد و تا زمان رسیدن دقیق ثانیه و آفست مورد نظر، هیچ درخواستی ارسال نخواهد کرد.
